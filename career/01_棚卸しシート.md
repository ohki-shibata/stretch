## 3. 実績の数字を洗い出す

「自慢できるか」で選ばない。**数字が出せるか**で選ぶ。

| 指標の種類 | 具体例 | 自分のケース |
|---|---|---|
| 売上・金額 | ARR、受注額、コスト削減額 | |
| 件数 | 契約社数、リード数、リリース本数 | |
| 率 | 継続率、CVR、改善率、削減率 | |
| 期間 | リードタイム短縮、立ち上げ期間 | |
| 規模 | チーム人数、予算、ユーザー数 | |
| 社内影響 | 仕組み化、横展開、標準化した範囲 | |

> 数字が出ない実績は「対象範囲 + 状態の変化」で書く。例：「属人化していた月次レポート作成を標準化し、担当者交代でも運用が止まらない状態にした」
